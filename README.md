# Bendik Strømme Røijem — personlig portefølje

En responsiv, norskspråklig porteføljeside for presentasjon av akademiske
resultater, prosjekter og CV.

Start den inkluderte webserveren:

```bash
npm start
```

Siden er da tilgjengelig på `http://localhost:8000`. Serveren støtter også
plattformstyrt port og vertsnavn gjennom miljøvariablene `PORT` og `HOST`:

```bash
PORT=8443 HOST=0.0.0.0 npm start
```
